# Гайд по использованию QGIS для поиска зданий

Пошаговый гайд с 35 действиями и скриншотами: поиск зданий по тегам локальной выгрузки OpenStreetMap, проверка близости леса и назначение приоритета по архитектуре.

## С чего начать

1. Выполнить [подготовку QGIS и данных](SETUP.md).
2. Открыть [гайд со скриншотами](guide.pdf).
3. В шаге подключения зон UTM использовать приложенный файл [utm_zones_north.geojson](assets/utm_zones_north.geojson).

## Пример поиска

| Признак | Условие |
| --- | --- |
| Территория | Россия |
| Номер дома | `12` или `42` |
| Тип здания | `building=apartments` |
| Этажность | `building:levels=2` или `3` |
| Крыша | `roof:shape=hipped` |
| Лес | Полигон `natural=wood` не дальше 10 м от контура здания |
| Архитектура | `stalinist_neoclassicism` получает приоритет 1, остальные варианты - 2 |

Архитектура влияет на порядок просмотра кандидатов. Она не исключает остальные здания и не означает рассчитанную вероятность. Условия `building:part=base` и `type=multipolygon` не применяются как обязательные.

В использованной локальной базе после проверки леса осталось 38 домов: 6 с приоритетом 1 и 32 с приоритетом 2. Это контрольные числа конкретного примера, выполненного 24 октября 2026 года; другая выгрузка OSM может дать иной результат.

## Файлы

- `guide.pdf` - основной гайд со скриншотами.
- `SETUP.md` - установка QGIS, необходимые данные и подготовка рабочего места.
- `assets/utm_zones_north.geojson` - вспомогательная сетка зон UTM с полем `utm_epsg`.
- `.gitignore` - исключение локальных карт и промежуточных результатов из коммита.

Гайд проверен на QGIS 3.44.15 для Windows. Основные операции выполняются в интерфейсе QGIS. Дополнительные плагины, Python-скрипты и Overpass для этого маршрута не требуются. Расчёт теней в гайд не входит.

Скриншоты содержат пути из рабочего примера. При повторении следует выбирать собственные папки; база России и готовый проект QGIS в этот комплект не включены.

# Встроенный посетитель страниц

Исходники используются обоими контейнерами из `tasks/kb-search/compose.yml`.
`policy.js` проверяет URL и управляет ограниченной последовательной очередью;
`visitor.js` создаёт одноразовый анонимный контекст Playwright и разрешает
только ресурсы своего приложения. Отдельного сервиса или входящего API нет:
форма `/report` передаёт задание очереди внутри процесса приложения.

Секреты сессий, коды демо-входа и флаги не передаются в browser context.
Скрипт страницы не получает cookie для доступа к профилю.

Запуск и ограничения описаны в `../kb-search/README.md`.
